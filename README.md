## NFSe Analyzer

NFSe Analyzer é uma ferramenta desktop que automatiza a leitura e consolidação de notas fiscais de serviço emitidas no Portal Nacional da NFS-e.

O programa abre o navegador do sistema, permite que o usuário realize o login normalmente no portal da NFS-e e, após acessar a tela de Notas Emitidas, realiza a leitura automática das notas exibidas na tabela, consolidando os dados em uma planilha Excel organizada.

A aplicação foi desenvolvida para facilitar a análise de notas emitidas, evitando a necessidade de exportação manual ou conferência individual das notas dentro do portal.
